# PaginaPessoal
"Crie uma página pessoal, pode ser sobre qualquer temática: sobre você, um personagem fictício, uma banda de música, etc.

Requisitos:
4 arquivos html navegáveis entre eles.
Usar as tags: header, nav, main, footer de forma adequada em todas as páginas.
Usar pelo menos as tags de conteúdo: p, img, h1.
Usar algumas tags de "formatação": b, strong, em, i, mark, small, del, ins, sub, sup (Não precisa usar todas).
Usar CSS, pode ser inline, internal, external (Preferencial o external).
Tente experimentar o máximo de recursos diferentes."
